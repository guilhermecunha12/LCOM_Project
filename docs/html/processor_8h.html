◆ get_event_handler()

EventHandler get_event_handler ( const StateType  state,
const EventType  event 
)

Get the appropriate event handler for the given GameState and EventType.

Internally, the implementation uses a 2D array indexed with GameState and EventType to retrieve the correct handler function. If no handler is defined for the given state and event type, it returns NULL.

Parameters
stateThe current state of the game, used to determine which set of event handlers to use.
eventThe current event type, used to determine which specific handler to call.
Returns
The appropriate function pointer to a event handler function.

Handler for serial port data events in the waiting for data state, in the receiver's perspective. This handler listens for data indicating the start of the night survival mode.

Only transitions to the receiving data state after a night survival is started. Therefore, if the receiver is set up in the middle of a night, it will only receive data from the next night forward.
