◆ kbc_ih()

void() kbc_ih ( )

Keyboard interrupt handler.

This function is called when a keyboard interrupt occurs. Called through process_scancode(), it simply reads a byte from the KBC output buffer and updates the last_byte_read variable, which is later used to build the scancode array. Only considers valid reads, as read_scancode() must return 0.

Function to subscribe to keyboard interrupts.

◆ process_scancode()

bool process_scancode ( )

Function to process a key's scancode (one or two bytes).

This function is responsible for the bulk of work related to processing a scancode. Works as a higher level wrapper, abstracting lower level details by using the other functions defined in this file. Calls the interrupt handler defined above to read the current byte issued from the KBC and available in the output buffer, then checks whether it's a single-byte or two-byte scancode and populates the scancode array accordingly.

Returns
true if the scancode has been completely read (whether it's a single-byte or two-byte scancode)
false if we are still reading a two-byte scancode

◆ reset_interrupts()

int reset_interrupts ( )

Function to reset the KBC interrupts (turns them back on).

In case of polling, the KBC interrupts are naturally turned off, so this function is used to turn them back on. It does so by issuing a read command byte to the command register, allowing to read the internal settings of the KBC and then setting the bit corresponding to enabling keyboard interrupts before writing the new command byte back to the KBC.

Returns
int 0 if successful, 1 otherwise.
