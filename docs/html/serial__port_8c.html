◆ get_received_data()

Queue * get_received_data ( )

Gets the queue of data received from the serial port from the receiver perspective.

Although the FIFO was set to generate an interrupt whenever there is at least 1 byte in the receiver FIFO, it was noticed that sometimes a single interrupt is generated for multiple bytes received in a short time interval. This is the reason why a queue was used to store the received data, so that all the received data can be processed in the interrupt handler, even if it was received in a single interrupt.

Returns
The queue of data received from the serial port.

◆ send_sp_data()

int send_sp_data ( uint8_t  data)

Sends data through the serial port, in the perspective of a transmitter.

This function waits until the Transmitter Holding Register (THR) of the serial port is empty and ready to accept new data to be transmitted, by checking the corresponding bit in the Line Status Register (LSR) of the serial port, and then writes the data to be transmitted to the THR register of the serial port.

Parameters
dataThe data to be transmitted.
Returns
0 on success, 1 on failure.

int serial_port_subscribe_int ( uint8_t *  bit_no)

Subscribes to the serial port interrupts exclusively. This function also stores the bit number of the interrupt in the location pointed to by the argument, which can be used later to identify the interrupt in the interrupt handler.

Parameters
bit_noInitially, a pointer to the bit position in the interrupt mask to be set to 1 in case of an interrupt. On success, its value is updated with the corresponding bit mask with a 1 in the *bit_no position (i.e., 1 << *bit_no).
Returns
0 on success, 1 on failure
