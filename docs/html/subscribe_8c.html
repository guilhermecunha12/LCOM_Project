Subscribes to the timer, keyboard and mouse interrupts and sets the VBE mode. If any of the operations fail, it unsubscribes from all devices and returns 1. Otherwise, it returns 0.

Parameters
timer_bit_noPointer to the variable that will store the bit number of the timer interrupt.
kbd_bit_noPointer to the variable that will store the bit number of the keyboard interrupt.
mouse_bit_noPointer to the variable that will store the bit number of the mouse interrupt.
com1_bit_noPointer to the variable that will store the bit number of the COM1 interrupt.
vbe_modeThe VBE mode to set.
Returns
0 if all operations were successful, 1 otherwise.
