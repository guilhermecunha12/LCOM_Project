Utility function to check if the mouse cursor is inside a given rectangular box. This is used for checking if the mouse is hovering over or clicking on interactive elements in the UI.

Parameters
mouse_xThe current x coordinate of the mouse cursor.
mouse_yThe current y coordinate of the mouse cursor.
box_xThe x coordinate of the top-left cornex of the rectangular box.
box_yThe y coordinate of the top-left cornex of the rectangular box.
box_wThe width of the rectangular box.
box_hThe height of the rectangular box.
Returns
Returns true if the mouse cursor is inside the rectangular box and false otherwise.
