Updates the animatronic's position and checks if it should attack the player.

This function updates the animatronic's AI level based on the time left in the night, checks if it's time for the animatronic to move, moves the animatronic forward in its path (or reset it to the start) or attacks the player.

Parameters
animatronicThe animatronic to be updated.
time_leftThe time left in the night, used to update the animatronic's AI level.
left_door_closedWhether the left door is closed, used to determine if the animatronic should attack the player.
right_door_closedWhether the right door is closed, used to determine if the animatronic should attack the player.
camera_monitor_upWhether the player has the camera monitor up, used to prevent Foxy from moving.
Returns
true if the animatronic attacks the player, false otherwise.
