void draw_mouse ( const GameState *  state)

This function is responsible for drawing the mouse cursor on top of everythin else.

The mouse is only drawn in states where it should be visible (MAIN_MENU and NIGHT_SURVIVAL). It uses the mouse coordinates stored in the global data of the game state to position the cursor sprite correctly on the screen.

This function is responsible for drawing the mouse cursor on top of everythin else.

This function draws the mouse in the coordinates given by the global game state and is called after everything else was drawn on the screen.

◆ render_frame()

void render_frame ( const GameState *  state)

Function to render the current frame based on the game state.

This function first checks if the state type is valid. It then clears the back buffer and retrieves the appropriate render handler for the current state type. If a handler exists, it calls the handler to render the specific elements of that state. After rendering the state-specific elements, it calls draw_mouse to ensure the mouse cursor is drawn on top of everything else. Finally, it swaps the buffers to display the rendered frame on the screen.

Parameters
stateA pointer to the current game state, which contains all the necessary information to determine what to render on the screen.
