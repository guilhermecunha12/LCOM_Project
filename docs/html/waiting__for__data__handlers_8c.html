Handler for keyboard events in the waiting for data state, in the receiver's perspective. This handler only listens for the escape key to allow exiting the game while waiting for data, since there is no other interaction possible in this state.

Parameters
statePointer to the current game state, which will be modified to exit the game if the escape key is pressed.
eventPointer to the current game event, which contains the keyboard input data.

const GameEvent *  event

Handler for serial port data events in the waiting for data state, in the receiver's perspective. This handler listens for data indicating the start of the night survival mode.

Only transitions to the receiving data state after a night survival is started. Therefore, if the receiver is set up in the middle of a night, it will only receive data from the next night forward.

Parameters
statePointer to the current game state, which can be modified to transition to the receiving data state.
eventPointer to the current game event, which contains the serial port data received.
