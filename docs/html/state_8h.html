Function that initializes the game state to the receiving data state and sets up the relevant data.

Parameters
statePointer to the GameState struct to initialize.
data_queueThe queue containing the data received from the serial port. This is necessary because animatronic's position data is sent in the begginning of the night survival mode (in the same interrupt as the data that starts the night), so we need to process that data to initialize the animatronics' positions in the receiving data state.
