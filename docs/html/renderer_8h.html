void draw_mouse ( const GameState *  state)

Draws the mouse sprite on the screen.

This function draws the mouse in the coordinates given by the global game state and is called after everything else was drawn on the screen.

Parameters

◆ get_render_handler()

RenderHandler get_render_handler ( const StateType  state)

Get the appropriate render handler for the given GameState.

Internally, the implementation uses a array indexed with GameState to retrieve the correct handler function. If no handler is defined for the given state, it returns NULL.

Parameters
stateThe current state of the game, used to determine which set of event handlers to use.
Returns
The appropriate function pointer to a render handler function.
