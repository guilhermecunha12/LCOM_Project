int update_keyboard_game_event ( GameEvent *  ge)

Updates the GameEvent struct based on the scancode received from the keyboard interrupt.

This function processes the scancode received from the keyboard interrupt, determines if it's a key press or release, and updates the GameEvent struct accordingly. It also normalizes the scancode to get the mapped key and updates the event data if the key is relevant for the game.

Parameters
geA pointer to the GameEvent struct to be updated with the keyboard event information.
Returns
int Returns 0 if the GameEvent was successfully updated with a keyboard event, or 1 if there was an error processing the scancode (e.g., no scancode available).

int update_mouse_game_event ( GameEvent *  ge)

Updates the GameEvent struct based on the mouse event information received from the mouse interrupt.

This function processes the mouse event information received from the mouse interrupt, including button states and movement deltas. It updates the GameEvent struct with the appropriate event type and fills in the event data with the relevant information.

Parameters
geA pointer to the GameEvent struct to be updated with the mouse event information.
Returns
int Returns 0 if the GameEvent was successfully updated with a mouse event, or 1 if there was no relevant mouse event to process.

Updates the GameEvent struct based on the serial port data received from the serial port interrupt.
