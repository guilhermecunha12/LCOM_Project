uint8_t encode_animatronic_data ( AnimatronicName  name,
CameraID  position 
)

Encodes the animatronic's name and position (camera) into a single byte of data to be sent through the serial port.

The encoding uses the 2 most significant bits to represent the animatronic's name, the next 4 bits to represent the camera number, and the 2 least significant bits to represent the camera letter (A, B or C).

Parameters
nameThe name of the animatronic to be encoded.
positionThe camera position of the animatronic to be encoded, which includes both the camera number and letter.
Returns
The encoded byte of data representing the animatronic's name and position.
