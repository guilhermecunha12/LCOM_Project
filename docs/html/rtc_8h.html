int rtc_read_date ( rtc_date *  date)

Function to read the current date from the RTC and fill the provided rtc_date structure.

This function ensures data consistency by checking the Update In Progress (UIP) flag before reading the date. It also checks the RTC configuration and performs data conversions if necessary (e.g. BCD to binary).

Parameters
datePointer to an rtc_date structure that will be filled with the current date read from the RTC.
Returns
Returns 0 on success, non-zero on failure.

◆ rtc_read_time()

int rtc_read_time ( rtc_time *  time)

Function to read the current time from the RTC and fill the provided rtc_time structure.

This function ensures data consistency by checking the Update In Progress (UIP) flag before reading the time. It also checks the RTC configuration to determine if the time is in BCD format and converts it to binary if necessary. Additionally, it handles both 12-hour and 24-hour formats, converting to 24-hour format if needed.

Parameters
timePointer to an rtc_time structure that will be filled with the current time read from the RTC.
Returns
Returns 0 on success, non-zero on failure.

Utility function to read a byte from a specified I/O port.

This function is a wrapper around the system call to read from an I/O port. It reads a 32-bit value from the port and then casts it to an 8-bit value, which is stored in the provided byte pointer.
