void move_player_screen_left ( GameState *  state)

Helper function to move the player's screen to the left.

This function was created since code would be duplicated in both night survival and night no battery handlers, and it is better to have it in a single place. It modifies the background movement direction to LEFT.

Parameters
statePointer to the current game state, which will be modified to update the background movement direction.
