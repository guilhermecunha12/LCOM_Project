Draws an entire row of pixels in the back buffer, starting at given coordinates, by performing a single memcpy operation.

This function is useful for efficient drawing of sprites without transparency, as we can draw entire rows of the sprite at once without needing to check each pixel for transparency.

Parameters
xThe horizontal coordinate of the first pixel in the row.
yThe vertical coordinate of the row.
