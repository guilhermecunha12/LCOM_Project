int16_t get_delta ( bool  sign_bit,
uint8_t  mouse_byte

Computes a coordinate's delta (x or y) of the mouse's movement in a 16-bit sign-extended integer.

In reality, the delta has only 9 bits (the 8 bits of the mouse byte plus the sign bit), but it is stored in a 16-bit integer for memory-alignment.

Parameters
sign_bitthe sign bit of the coordinate's delta, which is obtained from the first byte of the mouse packet. If the sign bit is 1, the delta is negative and needs to be sign-extended; otherwise, it is positive.
mouse_bytethe byte from the mouse packet that contains the least significant byte of the coordinate's delta.
Returns
the computed delta as a 16-bit signed integer.

int mouse_subscribe_int ( uint8_t *  bit_no)

Subscribes and enables mouse interrupts.

The value of *bit_no can never be greater than 7, otherwise, an overflow will occur when updating it with the bit mask.

Parameters
bit_noInitially, a pointer to the bit position in the interrupt mask to be set to 1 in case of an interrupt. On success, its value is updated with the corresponding bit mask with a 1 in the *bit_no position (i.e., 1 << *bit_no).

Returns 0 on success, 1 otherwise.

◆ process_packet()

bool process_packet ( )

Performs a step in processing a mouse packet.

This functions is called every time a new interrupt is received from the mouse and reads the new byte of the packet, updates the packet struct being read, and checks if the packet is complete (i.e., all bytes have been read). The uses a static variable byte_index to keep track of the current byte being read (0, 1 or 2) and updates it accordingly. When a packet is complete, the function resets byte_index to 0 to start reading the next packet. The function uses a naive way to find out the beginning of data packets, which is to check if the 3rd bit of the first byte is set (as it should be for the first byte of any packet) when it is waiting for the first byte (i.e., byte_index == 0).

Returns
true if the packet is ready (fully read) and false otherwise.

◆ send_to_mouse()

int send_to_mouse ( uint8_t  cmd)

Generic function to send a command directly into the mouse.

Before sending any command to the mouse, data reporting is disabled to prevent interference from packets sent by the mouse. After sending the command, data reporting is reenabled. The function also checks if the command was acknowledged by the mouse and retries if not.

Parameters
cmdthe command to be sent to the mouse.
Returns
Returns 0 on success, 1 otherwise.
