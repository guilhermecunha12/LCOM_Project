◆ handle_night_survival_timer()

void handle_night_survival_timer ( GameState *  state,
const GameEvent *  event 
)

Handler for timer tick events in the night survival state. This handler manages the countdown of the night survival time, checks for night completion, and handles battery drain based on player actions (doors, lights, camera). It transitions to the night 6AM screen if the player survives the night or to the no battery screen if the battery level reaches zero. It also updates animations and checks for animatronic jumpscares.

Parameters
statePointer to the current game state, which will be modified based on the night survival timer events, including time left, battery level, and potential jumpscares.
eventPointer to the current game event, which contains the timer tick data.
