Utility function to read a byte from a specified I/O port.

This function is a wrapper around the system call to read from an I/O port. It reads a 32-bit value from the port and then casts it to an 8-bit value, which is stored in the provided byte pointer.

Parameters
portThe I/O port to read from.
bytePointer to a uint8_t variable where the read byte will be stored.
