{\footnotesize\ttfamily void render\+\_\+frame (\begin{DoxyParamCaption}\item[{const \mbox{\hyperlink{structGameState}{Game\+State}} \texorpdfstring{$\ast$}{*}}]{state }\end{DoxyParamCaption})}



Function to render the current frame based on the game state. 

This function first checks if the state type is valid. It then clears the back buffer and retrieves the appropriate render handler for the current state type. If a handler exists, it calls the handler to render the specific elements of that state. After rendering the state-\/specific elements, it calls {\ttfamily draw\+\_\+mouse} to ensure the mouse cursor is drawn on top of everything else. Finally, it swaps the buffers to display the rendered frame on the screen. 
\begin{DoxyParams}{Parameters}
{\em state} & A pointer to the current game state, which contains all the necessary information to determine what to render on the screen. \\
