{\footnotesize\ttfamily bool process\+\_\+packet (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}



Performs a step in processing a mouse packet. 

This functions is called every time a new interrupt is received from the mouse and reads the new byte of the packet, updates the packet struct being read, and checks if the packet is complete (i.\+e., all bytes have been read). The uses a static variable byte\+\_\+index to keep track of the current byte being read (0, 1 or 2) and updates it accordingly. When a packet is complete, the function resets byte\+\_\+index to 0 to start reading the next packet. The function uses a naive way to find out the beginning of data packets, which is to check if the 3rd bit of the first byte is set (as it should be for the first byte of any packet) when it is waiting for the first byte (i.\+e., byte\+\_\+index == 0). \begin{DoxyReturn}{Returns}
true if the packet is ready (fully read) and false otherwise. 
\end{DoxyReturn}
